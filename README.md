# MAD Practical 5 – Login and Registration using Jetpack Compose

## AIM
To create an Android application that includes Login and Registration screens using Jetpack Compose.

## Project Description
This project demonstrates the development of an Android application with Login and Registration screens using **Kotlin and Jetpack Compose**. It provides a user-friendly interface for entering login credentials and registration details.

Jetpack Compose is a modern Android UI toolkit that allows developers to build native user interfaces using Kotlin code instead of traditional XML layouts.

## Features
- **Login Screen:** Provides input fields for user credentials.
- **Registration Screen:** Allows users to enter their details to register.
- **User Input:** Uses text fields to accept user information.
- **Interactive UI:** Includes buttons for login and registration actions.
- **Modern Design:** Uses Jetpack Compose UI components.
- **Kotlin Support:** Implements the application using Kotlin.

## Technologies Used
- **Language:** Kotlin
- **IDE:** Android Studio
- **UI Toolkit:** Jetpack Compose
- **Platform:** Android

## Concepts Covered
1. Introduction to Jetpack Compose.
2. Composable functions using `@Composable`.
3. Layouts using `Column`, `Row`, and `Box`.
4. Text input using `TextField` and `OutlinedTextField`.
5. Buttons using `Button`.
6. State management using `remember` and `mutableStateOf`.
7. Handling user interactions.
8. Creating Login and Registration screens.
